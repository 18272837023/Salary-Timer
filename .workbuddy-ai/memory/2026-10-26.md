## 本地预览环境（Salary Timer / Next.js）

- **端口占用**：3000、3100 被本机另一个 Next 项目占用（进程 2516 / 11224），**不要用这两个端口**；开发服务器固定用 **3210**。
- **踩坑（重要）**：`next dev` 从 `http://127.0.0.1:PORT` 打开时，Next 16 默认拦截跨源 dev 资源（`/_next/hmr` 等），表现为页面正常渲染但**完全不 hydrate**——计时器永远 `$0.00`、按钮无响应、控制台只有一条 React DevTools 提示，无报错。已通过 `next.config.mjs` 加 `allowedDevOrigins: ["127.0.0.1", "localhost"]` 修复。若以后换端口或换机器复现"页面能看但不能点"，先查这个。
- **当前运行中的两个服务**：
  - `http://127.0.0.1:3210/` — `next dev`（源码热更新，日常查看用）
  - `http://127.0.0.1:8850/` — `out/` 静态产物的 http.server（生产态，验收用）
- 验证方法：CDP 连 Chrome 时**必须按 `type === 'page'` 选 target**，否则会连到扩展的 background.html，所有 querySelector 返回 undefined，误判成页面坏了。
