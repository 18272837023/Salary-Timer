## 代码审计发现的待修缺陷（19:56，未修）

用户质疑「是不是只有 Demo 水准」，遂实测代码，确认以下硬缺陷：

1. **金额分位截断错误（真 bug）**：`index.html:1361` 用 `Math.floor((v-whole)*100)` 渲染分位，浮点误差导致约 **49.8%** 的情况下少显示 1 分。实测 `hourly=38.46, paidElapsed=279.6` → 真实值 179.2236，显示 $179.22（应为 .22，此处偶然正确；扫描 8~120 美元时薪 × 0~480 分钟共 43.7 万组，49.8% 偏差）。修法：全链路改用整数分（cents）运算，仅在渲染时除 100。
2. **localStorage 静默失败**：`save()` 是 `try{}catch(e){}` 空捕获，Safari 无痕模式下用户改完设置以为存上了，实际全丢，无任何提示。需降级到内存态 + toast 告知。
3. **无 Service Worker**：只有 manifest，断网即白屏，"works offline" 这句文案目前是假的。
4. **只在 Chrome headless 测过**：iOS Safari 未验证，而这个产品的核心用户就是手机上的轮班族，风险最高。
5. 无自动化测试留存（之前的断言脚本跑完即删）、无全局 error handler、无 a11y 审计、无 i18n。

**结论/决策待定**：纯静态单文件本身不是问题（无路由/无请求/单状态，React 无收益），但若要长成多页长尾站，应上 Astro 或 Next.js SSG（不可用 React SPA——CSR 会砸掉 SEO 需求）。

**技术栈定性**：HTML5 + 原生 CSS（变量/Grid/clamp）+ 原生 JS（无框架无构建）、localStorage 持久化、唯一外部依赖是 Google Fonts（Baloo 2 / Nunito）。纯静态，可直接丢任何静态托管。

**上线前剩余 3 项**：① 域名占位 `salarytimer.app` 需替换（canonical / og:url / og:image / twitter:image / sitemap.xml / robots.txt）；② Google Fonts 在国内访问慢，建议自托管 woff2 或换 fonts.bunny.net；③ 面向欧美接广告/联盟前补 privacy + terms 页。
